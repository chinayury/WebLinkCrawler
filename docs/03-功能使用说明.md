## 2. 页面一：任务布设（`targets`）

**顶栏标题**：`任务布设`；**副标题**：`录入目标与筛选条件，落定即开跑`。

页面为纵向滚动画布，含三块面板，均可鼠标滚轮滚动。

### 2.1 面板「目标清单」

**面板标题**：`目标清单`；**副标题**：`每行一条网址，# 开头为注释`；图标 `globe`。

| 控件 | 说明 |
| --- | --- |
| 字段眉头 | `网址清单` + 说明 `每行一条` |
| 多行文本框 | 默认形态（`multi_url.enabled=true`）：5 行等宽文本区，每行一条网址；以 `#` 开头的行视为注释，不参与抓取；空行忽略 |
| `导入清单` | 从文本/CSV 文件批量导入 URL；自动按 `utf-8-sig → utf-8 → gb18030 → gbk → big5 → latin-1` 顺序尝试解码，最后兜底 `utf-8` 替换解码；导入前去重（保持原顺序）并覆盖文本框 |
| `导出清单` | 把当前文本框内容写入文本文件，文件头含「URL 列表导出 / 导出时间 / URL 数量」；默认文件名 `urls_YYYYMMDD_HHMMSS.txt` |
| `校验地址` | 统计有效/无效 URL 数量并列出前 10 个无效项；询问「是否只保留有效 URL？」，确认后仅回填有效项 |

> 当 `multi_url.enabled` 被置为 `false` 时，该面板改为「网页地址」单行输入框形态。**切换该项需重启程序后生效**。

**网址规范化规则**（输入即生效，`config.py` `normalize_url`）：

- 不含 `://` 的裸主机名/路径自动补 `https://`；
- `javascript:` / `data:` / `mailto:` 等非 http(s)/ftp(sftp) 伪协议**不改写**，交由校验层拒绝；
- scheme 与 host 转小写、丢弃 fragment、剥离 `user:pass@` 凭据；
- 非法输入原样返回，由 `is_valid_url` 判定（协议 + 主机名双重校验）。

### 2.2 面板内子区「范围限定」

**字段眉头**：`范围限定` + 说明 `仅抓取指定元素内的链接`。

| 控件 | 行为 |
| --- | --- |
| `网页预览选元素` | 有 PyQt5 + QtWebEngine 时的文案；取网址清单**第一条** URL，启动独立预览子进程点选元素 |
| `网页预览选元素（降级）` | 未检出 QtWebEngine 时的文案 |
| `手动填写 CSS 选择器` | 打开「元素选择器」对话框手工填写 |
| 当前选择器显示 | `当前选择器：{选择器或「整个页面」}`，随配置实时刷新 |

选择器语义：留空 = 整个页面；填写后只提取该 CSS 选择器命中元素内的链接；选择器无效或选不到元素时**回退整页**（`crawler.py` `_crawl_round`）。

### 2.3 面板「筛选规则」

**面板标题**：`筛选规则`；**副标题**：`按类型、协议与关键词收敛结果`；图标 `filter`。

| 控件 | 说明 |

| `单选模式` / `多选模式` | 单选钮，切换筛选控件形态 |
| 单选模式下拉框 | 只读下拉，默认 `所有链接`；选项 = `所有链接` / `HTTPS链接` / `HTTP链接` + 11 个文件类型分类 |
| 多选模式复选框 | 11 个文件类型分类两列排布，配 `全选` / `取消全选` 按钮；一个都没勾时等同「所有链接」 |

### 2.4 面板「执行控制」

**面板标题**：`执行控制`；**副标题**：`启动、暂停、续爬与结果体检`；图标 `pulse`。

**第一行按钮**：

| 按钮 | 行为 |
| --- | --- |
| `开始抓取` | 校验输入后启动后台抓取线程；抓取中禁用，`停止`/`暂停` 可用 |
| `暂停` | 协作式暂停，按钮文字变 `恢复`；再点恢复 |
| `停止` | 请求停止抓取，日志记 `正在停止抓取…` |
| `断点续爬` | 从数据库恢复未完成任务（状态 `pending`/`crawling`/`stopped`），跳过已访问页面、合并已有结果 |

**第二行按钮**：

| 按钮 | 行为 |
| --- | --- |
| `应用筛选` | 按当前筛选条件收敛结果；无结果时弹「请先抓取链接。」 |
| `链接体检` | 对「当前筛选结果（非空时）否则全部记录」发起并发 HEAD 体检；体检期间按钮禁用、进度条走 `体检中 x/N` |
| `导出结果` | 打开导出对话框，支持 TXT / CSV / JSON |
| `清空工作区` | 清空结果记录、网址清单、关键词、筛选下拉与结果区；日志记 `已清除所有内容。` |

**进度区**：进度条 + 状态行。状态文案随阶段变化：`就绪 · 等待开始` → `抓取中…` → `恢复中…` → `体检中 x/N` → `已抓取页面：{url}  →  {n} 个链接`，结束后回到 `就绪 · 等待开始`。

### 2.5 抓取过程的行为规则（代码事实）

| 规则 | 说明 | 代码位置 |
| --- | --- | --- |
| 起始 URL 过滤 | 仅 http/https 目标参与抓取，其他协议记 `[跳过]非 HTTP(S)目标` | `crawler.py` `crawl` |
| 下钻条件 | 仅同主机（host:port 相同）、非文件链接、未被排除规则的链接继续下钻 | `crawler.py` `_crawl_round` |
| 层级模型 | BFS 按层抓取；记录中的 `depth` 表示「发现该链接的页面所在层级」，0 = 来自起始页 | `crawler.py` |
| 页数上限 | 全局 `max_pages`（默认 200），超限记 `已达到页面上限 {n}，停止扩展。` | `crawler.py` |
| robots.txt | 默认遵循；被禁记 `[robots拒绝]`；支持 `*` 通配、`$` 锚定、Allow 最长匹配优先 | `crawler.py` `robots_allows` |
| 限流退避 | 429/503/408 先按 Retry-After 或指数退避重试，次数用尽记 `[放弃重试]`，**不抽取错误页链接** | `crawler.py` `_fetch_with_retry` |
| 请求间隔 | `interval` 既作正常请求节流（同一主机，实际间隔在 interval ~ 2×interval 间随机），也作重试退避基数 | `crawler.py` `_throttle` |
| Content-Type 闸门 | 仅 `text/html` / `application/xhtml+xml` / `text/plain` 解析子链接，其他记 `[跳过解析] … 非可解析内容类型` | `crawler.py` `_should_parse_body` |
| 去重 | 「原始 URL + canonical key」双轨：导出与入库写原始 URL，canonical key 只作去重键 | `crawler.py` `_normalize_links`、`config.py` `canonical_key` |
| 文件过滤 | 开启大小/时间过滤时，对文件链接并发探测 Content-Length / Last-Modified | `crawler.py` `_passes_file_filters` |

**顶栏标题**：`结果清册`；**副标题**：`排序、筛选、体检，落定后导出`。

**面板标题**：`链接清册`；**副标题**：`点表头排序，体检后显示存活状态`；图标 `table`。

### 3.1 表格视图

页签文字为 `  表格视图  `（含前后空格）。

| 列 | 列宽 | 排序键 | 说明 |
| --- | --- | --- | --- |
| `#` | 52 | `link` | 序号，从 1 开始 |
| `链接` | 760（可拉伸） | `link` | 原始 URL |
| `类型` | 120 | `file_type` | 文件类型分类，无匹配显示 `—` |
| `协议` | 76 | `protocol` | https / http / ftp / sftp，空显示 `—` |
| `深度` | 66 | `depth` | 发现层级，空显示 `—` |
| `状态` | 96 | `state` | 体检状态文案，见下表 |

- 点击表头排序；再次点击同一列切换升/降序。
- 行高 30，表格只绘制横向细线（无竖线、无斑马纹）。

### 3.2 状态文案与配色

| 内部状态 | 界面文案 | 表格标签色 |
| --- | --- | --- |
| `ok` | 可用 | 成功色 |
| `redirect` | 重定向 | 信息色 |
| `dead` | 失效 | 危险色 |
| `blocked` | 受限 | 警示色 |
| `error` | 异常 | 次文本色 |
| `""`（未体检） | 未检 | 三级文本色 |

体检判定规则（`crawler.py` `check_links` / `_classify_status`）：

- 2xx 一律 `ok`；`link_check.ok_status_codes`（默认 `[200, 206, 999]`）也判 `ok`，且该判定早于 3xx；
- 3xx → `redirect`；`401/403/429` → `blocked`；`404/410` → `dead`；其余 → `error`；
- HEAD 取到 `405/501`（403 为 opt-in）时回退一次**只读 GET**（不读 body），用 GET 的状态码重新分级；
- ftp/sftp 链接不发起请求，直接记 `error`（原因「ftp/sftp 协议不支持自动体检」）。

### 3.3 文本视图

页签文字 `  文本视图  `；等宽字体，首行 `找到 {n} 个匹配的链接：`，随后是 50 个 `=` 分隔线与 `序号. 链接` 列表；无结果时显示 `没有找到匹配的链接。`。

| 按钮 | 行为 |
| --- | --- |

## 6. 对话框与弹窗

### 6.1 增强功能配置

标题 `增强功能配置`；保存/取消栏固定在底部，长表单可滚动。

| 分区 | 可配置项 | 取值范围 / 说明 |
| --- | --- | --- |
| 基础 | `启用增强功能` | 关闭后深度抓取、文件过滤、反反爬等增强能力不生效 |
| 多 URL 抓取 | `启用多 URL 模式` / `启用批量导入（文件导入 URL）` / `启用 URL 格式校验` | 多 URL 模式切换需重启后生效 |
| 抓取深度与上限 | `启用深度抓取`；深度单选 `仅当前页(0)` / `+1 级(1)` / `+2 级(2)` / `自定义(3)`；自定义深度 1~5 | 关闭深度抓取等价 depth=0 |
| | `最大抓取页数(1~100000)` / `并发数(1~64)` | 默认 200 / 8 |
| 排除规则 | `启用排除规则` / `使用正则（否则按通配符匹配）`；规则每行一条 | 例 `*.jpg`、`/ads/` |
| 元素抓取 | `启用元素抓取`；`默认 CSS 选择器（留空 = 整个页面）` | 关闭后不使用全局选择器 |
| 文件过滤 | `启用文件过滤` / `启用大小过滤（仅对文件链接生效）`；最小/最大 MB（≥0，0=不限）/ `启用时间过滤（按 Last-Modified）`；最近天数 1~365 | 大小过滤要求最小 ≤ 最大 |
| 断点续爬 | `启用断点续爬（任务与链接实时入库）` | 关闭后「断点续爬」不可用 |
| 反反爬与请求策略 | `启用反反爬` / `动态 User-Agent（从 UA 列表随机选择）`；UA 列表每行一个 | 默认 4 条 UA |
| | `启用代理`；代理类型 HTTP / SOCKS5；代理列表每行一个（`host:port` 或 `user:pass@host:port`） | 非法类型回落 `http` |
| | `启用 Cookie`；Cookie 列表每行一个 `k=v` | 无 `=` 的项被跳过 |
| | `启用请求策略（间隔/重试/超时）`；`间隔(s)0~60` / `重试 1~10` / `超时(s)3~120` | 间隔为**同一主机**的请求节流，实际间隔在该值与其 2 倍间随机 |
| 网络安全 | `遵守 robots.txt` / `阻止重定向到内网/私有地址`；`HTML 上限(字节 65536~104857600)` / `重定向上限(0~20)` | 默认 5 MB / 5 次 |

- 保存时逐项做整数/浮点与范围校验，非法输入弹「参数错误」并说明原因。
- 保存成功弹「增强功能配置已保存。」，写入 `enhanced_config.json`。
- **仅能通过编辑配置文件修改的键**（GUI 未暴露）：`content_gate`、`link_check`、`dedup_query`、`network_policy.ssl_compat_legacy_servers`、`network_policy.block_private_targets`、`anti_anti_crawl.request_strategy.retry_after_cap`。详见 `02-环境部署教程.md` §6.1。

### 6.2 编辑文件类型映射

标题 `编辑文件类型`；眉头 `编辑文件类型映射` / `左侧选择分类，右侧维护该分类的扩展名`。

- 输入行：`新分类:` 与 `新扩展名(逗号分隔):`。
- 按钮：`添加分类`（支持逗号分隔批量，重复分类忽略）、`删除分类`（需确认）、`添加扩展名`（自动补 `.` 前缀并转小写，重复忽略）、`删除扩展名`。
- `保存更改`：写回 `file_type_config.json`，并刷新筛选下拉框与多选复选框，弹「文件类型映射已更新。」。

### 6.3 元素选择器

标题 `元素选择器`；眉头 `元素选择器` / `用 CSS 选择器指定要抓取链接的区域`。

### 6.4 网页预览选元素

**（a）PyQt5 + QtWebEngine 子进程**（`preview.py`）：

- 由 `app.py` 以「当前解释器 + `preview.py` 绝对路径 + `--url URL --result 临时JSON`」启动独立进程（工作目录为项目根目录），与 Tk 事件循环分进程运行。
- 窗口标题 `网页预览 -选择页面元素`，工具栏 `刷新` / `选择元素 (Ctrl+Shift+C)` / `DevTools (F12)`，右侧状态标签。
- 点选后弹出 `确认 CSS选择器`，选「是」写入 `css_selector` 并退出；选「否」可继续点选；直接关闭窗口写 `cancelled`。
- 主程序每 300ms 轮询结果文件，最多 600 次（约 3 分钟），超时记 `网页预览超时（约 3 分钟），已关闭预览进程。`。
- 已有预览窗口在运行时再点按钮，弹「网页预览窗口已在运行，请先完成或关闭它。」。

**（b）内置降级预览**（无 QtWebEngine 或子进程启动失败时自动回退）：

- 窗口 900×650，标题 `网页结构预览 - {url}`；眉头 `网页结构预览` / `预览页面结构，点击任意标签行以提取 CSS 选择器`。
- 后台线程抓取页面并用 BeautifulSoup 美化输出；加载失败显示 `加载失败: {原因}`。
- 点击任一行：有 `id` 属性取 `#id`，否则有 `class` 取 `.a.b`，否则取标签名；写入配置并关闭窗口。

## 7. 导出格式

导出对话框默认文件名 `links_YYYYMMDD_HHMMSS.txt`，文件类型 `文本文件(*.txt)` / `CSV 表格(*.csv)` / `JSON 数据(*.json)` / `所有文件(*.*)`；扩展名不在 txt/csv/json 时按 txt 处理。导出的是**当前筛选结果**。

**TXT**（兼容旧版式）：

```text
抓取自: {source}
抓取时间: {YYYY-MM-DD HH:MM:SS}
筛选类型: {所有链接 / HTTPS链接 / 分类名 / 多选}
关键词: {keyword}
CSS选择器: {selector 或 整个页面}
链接数量: {n}
================================================

  1. https://example.com/a
```

**CSV**（`utf-8-sig`，Excel 可直接识别中文）：表头 `序号,链接,文件类型,协议,深度,状态`。以 `=` `+` `-` `@` 或制表/回车开头的单元格加单引号前缀中和公式注入。

**JSON**：`{"meta": {source, crawl_time, filter_type, keyword, css_selector, count}, "links": [{index, link, file_type, protocol, depth, state}, ...]}`。

> 元信息中的 `source` 取网址清单文本框第一行（或单行模式的输入框内容）。

## 9. 使用提示与已知限制

| # | 事项 | 说明 |
| --- | --- | --- |
| 1 | 深度含义 | `depth=0` 表示链接来自起始页；`+1 级` 会再抓一层同域页面 |
| 2 | 同域限制 | 只有与起始 URL 同主机的链接会继续下钻，外站链接只记录不下钻 |
| 3 | 去重口径 | `utm_source` 等噪声参数不产生新记录，`?page=2` / `?id=` 等真参数永不被误删；导出仍是原始 URL |
| 4 | 体检与抓取分层 | 能否解析子链接看 Content-Type；是否存活看体检 HEAD，两者互不重复过滤 |
| 5 | ftp/sftp 状态 | 体检对 ftp/sftp 零请求直接记「异常」，属已知设计 |
| 6 | CSV 公式注入 | 已对 `=` / `+` / `-` / `@` 开头单元格加单引号前缀中和 |
| 7 | 单 URL 模式 | 关闭 `multi_url.enabled` 后需重启才变为单行输入框 |
| 8 | 文件类型变更 | 修改映射后需在编辑器内点「保存更改」才会刷新筛选控件 |
| 9 | 退出确认 | 抓取中关闭窗口会弹「抓取正在进行，确定退出？」，确认后停止抓取并清理预览子进程 |
